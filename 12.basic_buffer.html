Basic Buffer (NH₄OH + NH₄Cl)

Weak Base (NH₄OH)
Ammonium Ion (NH₄⁺)
Added H⁺ (Acid) / OH⁻ (Base)
pH = 9.26 (Constant — Resists Change)

📌 Basic Buffer Action

  • • Composition: Weak base (NH₄OH) + its salt with strong acid (NH₄Cl).
  • • Add H⁺ (Strong Acid): NH₄OH + H⁺ → NH₄⁺ + H₂O (H⁺ consumed, pH unchanged).
  • • Add OH⁻ (Strong Base): NH₄⁺ + OH⁻ → NH₄OH (OH⁻ consumed, pH unchanged).
  • • Henderson Equation: pOH = pKb + log₁₀([Salt]/[Base])
