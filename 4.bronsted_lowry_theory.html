Proton Transfer (NH₃ + H₂O)

12th HSC • Ch 3: Ionic Equilibria (3D Model)

Transferable Proton (H⁺)
Nitrogen Core (NH₃ / NH₄⁺)
Oxygen Core (H₂O / OH⁻)
NH₃ (Base) + H₂O (Acid) ⇌ NH₄⁺ + OH⁻

📌 Bronsted-Lowry Theory

  • • Bronsted Acid: Proton (H⁺) donor (Ex: H₂O → H⁺ + OH⁻).
  • • Bronsted Base: Proton (H⁺) acceptor (Ex: NH₃ + H⁺ → NH₄⁺).
  • • Conjugate Acid-Base Pair: Differ by a single proton (H⁺). Example: NH₄⁺ / NH₃ and H₂O / OH⁻.
