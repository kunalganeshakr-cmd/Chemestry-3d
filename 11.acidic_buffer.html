Acidic Buffer (CH₃COOH + CH₃COONa)

12th HSC • Ch 3: Ionic Equilibria (3D Model)

Weak Acid (CH₃COOH)
Acetate Ion (CH₃COO⁻)
Added Strong Acid (H⁺) / Base (OH⁻)
pH = 4.74 (Constant — Resists Change)

📌 Acidic Buffer Action

  • • Composition: Weak acid (CH₃COOH) + its salt with strong base (CH₃COONa).
  • • Add H⁺ (Strong Acid): CH₃COO⁻ + H⁺ → CH₃COOH (H⁺ consumed, pH unchanged).
  • • Add OH⁻ (Strong Base): CH₃COOH + OH⁻ → CH₃COO⁻ + H₂O (OH⁻ consumed, pH unchanged).
  • • Henderson Equation: pH = pKa + log₁₀([Salt]/[Acid])
